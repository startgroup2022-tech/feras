## ملفات الحزمة

- SPECIFICATION.md: النطاق، الروابط، الصفحات، النماذج، البيانات، التشغيل، التصميم، الفهرسة، النواقص واختبارات القبول.
- content/ARABIC.md: نصوص الصفحات العربية؛ شركات المجموعة في companies.json ورسائل النماذج في messages.json.
- content/companies.json: الأسماء والبيانات والنصوص الكاملة والبطاقات للشركات التسع بالعربية والإنجليزية. null = غير مقدم، ولا يعني صفرًا أو نصًا للنشر.
- content/ENGLISH.md: النسخة الإنجليزية الكاملة للمراجعة المجمعة.
- content/PRIVACY-AR.md: أجزاء الخصوصية العربية المعتمدة مع ملاحظة استكمال داخلية.
- content/messages.json: رسائل النماذج والتنبيهات باللغتين.
- content/options.json: الخدمات والدول باللغتين؛ معرفات ثابتة مقترحة للتنفيذ.
- previews/: معاينات مرئية + مصادرها؛ ليست تطبيقًا جاهزًا للإطلاق.
- assets/: الشعار وصورة الواجهة المرجعية وسجل المصادر والنواقص.
- CHECKS.md: فحوص الحزمة نفسها؛ لا يثبت اختبار موقع إنتاج.

## ترتيب المرجعية

1. أي قرار أحدث يقره المالك بعد هذه الحزمة.
2. النصوص العربية وقرارات المواصفات المعتمدة من المحادثة.
3. المعاينات للشكل والتوزيع فقط؛ لا تُؤخذ منها الافتراضات أو الأمثلة كنصوص إنتاج.
4. الإنجليزية والمقترحات التقنية تحتاج المراجعة المجمعة الموضحة.

## قرارات لاحقة تنسخ التسليم القديم

الشركات في الرئيسية قائمة تفاعلية على الكمبيوتر وaccordion على الجوال، وليست شبكة تسع بطاقات.
صور المشروع متعددة واختيارية؛ لا إلزام بصورة واحدة.
البروفايل والشعارات/الروابط غير المقدمة مؤجلة؛ لا نطالب المالك بها مرارًا، ولا نخترعها.
الرئيسية والصفحات الداخلية والهوية اعتمدت؛ النص الإنجليزي في هذه الحزمة جديد للمراجعة.
الصورة الجديدة لخليج البحرين هي المرجع البصري، وصورة المنامة السابقة ملغاة.
